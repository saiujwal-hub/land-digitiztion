How the reading works

Four passes between ink and data.

Sankalan reads a document the way a careful clerk would — but shows its work. Every value on the right-hand side of the bench can be traced back to the strokes it came from.

PASS 1

Detect

Page geometry, table lines and stamp impressions are found; handwriting zones separated from print.

PASS 2

Read

OCR reads Devanagari and Latin text, including handwritten numerals, with per-word confidence.

PASS 3

Assemble

NLP groups words into labelled fields — survey, khasra, khata, area, parties — using register layouts.

PASS 4

Challenge

Validation rules cross-check the fields against each other; contradictions and low confidence are flagged.
