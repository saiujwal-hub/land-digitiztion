# SYNTHETIC / DEMO DATA — NOT REAL GOVERNMENT DATA

## Overview
This directory contains purely synthetic demonstration GIS data for testing the OneBhoomi spatial dataset schema and onboarding pipeline.
**THIS IS NOT REAL GOVERNMENT DATA.** None of the geographic coordinates, boundaries, village names, or administrative structures represent real-world legal land records.

## Files
- `demo_state_spatial_registry.json`: Synthetic ADM2 (district) and ADM3 (mandal) boundary polygons.
- `demo_state_villages.geojson`: Synthetic ADM4 village boundary polygons.
